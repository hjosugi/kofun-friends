# cursors — Mouse Cursors

- `svg/` : Original vector files for editing
- `png/` : For web use (`cursor: url(...)`)
- `ani/` : For Windows `.ani` / `.cur` (manually placed, not included in converter)

Hotspots are recommended near the top-left, with sizes around 32px.
