# 素材サイト

外部素材を使用する前に、再配布・改変・商用利用の可否を確認します。

## 現在使っているもの

- OpenGameArt: [Warped City](https://opengameart.org/content/warped-city)
  - local: `assets/backgrounds/cc0/warped-city/`
  - license: 同梱の `LICENSE.txt` でパブリックドメイン / 商用利用可 / クレジット不要を確認
- OpenGameArt: [Skyline Background](https://opengameart.org/content/skyline-background)
  - local: `assets/backgrounds/cc0/skyline-background/`
  - license: 同梱の `LICENSE.txt` でパブリックドメイン / CC0 を確認
- Lospec: [Cyberpunk Neon City](https://lospec.com/palette-list/cyberpunk-neon-city)
  - use: 色の参照のみ。画像はコピーしない

## 使い方

- CC0 / パブリックドメイン: `assets/` に入れてよい。URLとライセンスを保存する。
- CC BY: クレジットを残せる場合のみ使用する。
- 再配布禁止: このリポジトリには入れない。
- Google画像検索 / SNS / Pinterest: 参考のみ。保存して素材化しない。

## チェック

1. 元のURLを残したか。
2. 作者名を残したか。
3. ライセンス本文を保存したか。
4. `catalog/manifest.json` に正しい `license` を記載したか。
